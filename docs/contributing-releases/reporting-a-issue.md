# Reporting an issue

Use Jira Cloud to report bugs, documentation gaps, and change requests:

[:simple-jira: Open Jira Cloud](https://rhughes1.atlassian.net/){ target=_blank .md-button .md-button--primary }

## What to include

Every issue should include:

- Summary
- Steps to reproduce
- Expected result
- Actual result
- Tooling versions
- Supporting context or screenshots, when useful

## Suggested template

Use this structure when opening a Jira Cloud issue:

### Summary

One or two sentences describing the problem.

### Steps to reproduce

Numbered steps that reliably trigger the issue.

### Expected result

What you expected to happen.

### Actual result

What happened instead.

### Tooling versions

List the relevant versions for the tools involved, for example:

- Terraform
- provider versions
- CLI tools
- runtime or platform versions

### Supporting context

Add logs, screenshots, links, or other details that help explain the issue.

If you are creating an epic or story instead of a bug, use [Work items](jira-work-items.md) for the matching template and story acceptance criteria. If the work is not tied to Jira, use the same structure for the matching work item and keep the headings unchanged.
